## What it does

`grill-me` is the user-invoked wrapper. Typing it starts a `/grilling` session. The agent should not invent a different interview style.

## When to reach for it

Whenever you want to force alignment before work: a plan, a value case, a go-live, a risky change.

## Install note

`grill-me` only works if `grilling` is installed beside it.
