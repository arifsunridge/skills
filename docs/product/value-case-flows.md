## What it does

Turns "how did this work before, and how does it work now" into one interactive Sunridge flows page: data flow, process swimlane, deep dives, what changed, still manual.

## When to reach for it

Portco value cases, before/after process changes, or any ask to "draw the flows".

## Steps (agent)

1. Write the brief (owners, measures with source + date + legend tag)
2. Trace claims from evidence
3. Model markers and tables
4. Draw SVGs with the bundled scripts
5. Build `page.html` from `spec.json`
6. Check with screenshots
7. Publish as an HTML artifact

## Rules

Counts and dates over vanity. Money only where allowed. Draft until the owner signs off. Still-manual work stays visible.
