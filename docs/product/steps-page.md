## What it does

Builds a clickable **steps page** for procedures only a human can do in a browser: exact links, Copy buttons, remembered ticks, and blue hand-back boxes that paste back into chat when the agent must act.

## When to reach for it

Deploys, go-lives, portal grants, dashboard clicks you cannot do from tools. Prefer Matt-style `wizard` only when the person has a terminal.

## Steps (agent)

1. Scope actions only the person can take
2. Order by site / screen; deploy gate last; look-around last
3. Fill the `PAGE` block in `template.html`
4. Check once, then publish

Aim for 4–8 steps. Deep links beat directions.
